# Spencer Duncan portfolio

A small, accessible portfolio site built with React, TanStack Start, Vite, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

The development server uses `0.0.0.0:8080`.

## Quality checks

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

The site currently avoids analytics, advertising cookies, accounts, databases, and contact-form storage. The `/privacy` page documents the current data practices. Replace placeholder portfolio claims, LinkedIn URL, and canonical deployment URL before production launch.
